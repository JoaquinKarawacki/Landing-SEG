No editar archivos directamente. En cambio, describir exactamente qué cambiar y dejar que el usuario lo haga.

**Why:** El usuario quiere control sobre los cambios y prefiere aplicarlos él mismo.

**How to apply:** Siempre indicar archivo, línea/sección, y el texto exacto a reemplazar. No llamar a Edit/Write sobre código del proyecto.
